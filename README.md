# TechZone E-Commerce Website

TechZone is a responsive technology storefront built as a college web-development project. It provides product discovery, category filtering, sorting, cart management, payment-method selection, and a demonstration checkout flow.

## Features

- Responsive desktop, tablet, and mobile design
- Product search and category filters
- Price sorting
- Add-to-cart functionality
- Cart quantity and removal controls
- Card, UPI, and cash-on-delivery selection
- Demo checkout notifications
- Empty search and empty cart states

## Technology

- Next.js
- React
- TypeScript
- Tailwind CSS
- Radix UI
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Production build

```bash
npm run build
npm start
```
